# EC AIR EXCITER - by EC AUDIO - macOS Only

Excitador armónico estilo Fresh Air, estética clara EC AUDIO.

## Features
- **MID AIR:** Presencia 2kHz - 8kHz. Default +2.4 dB
- **HIGH AIR:** Brillo aéreo 10kHz - 20kHz. Default +4.1 dB
- **MIX:** 0 - 100%. Default 65%
- **OUTPUT:** -24dB a +12dB. Default -0.5 dB
- **POWER / BYPASS**
- **PRESET:** Warm & Airy (default)
- **OVERSAMPLE 2x + SAFE**

## Compilar en GitHub - Solo Mac
1. Sube este repo a GitHub
2. Ve a **Actions** -> Espera 3-5 min
3. Descarga Artifact: `EC-AIR-macOS-VST3-AU`

## Instalación macOS
- **VST3:** `~/Library/Audio/Plug-Ins/VST3/EC AIR EXCITER.vst3`
- **AU:** `~/Library/Audio/Plug-Ins/Components/EC AIR EXCITER.component`

## Presets
- Warm & Airy (Default) - Mid +2.4dB / High +4.1dB / Mix 65%
- Vocal Air
- Master Shine
- Drum Air
- Solo High Air
